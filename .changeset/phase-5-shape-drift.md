Phase 5: shape drift detection — observed response shapes vs. the synced IR, surfaced on the dashboard's coverage tab.

- **`@demokit-ai/core`**: `deriveShape` (spec §9.4) walks a response into a values-free `ShapeNode` descriptor — keys, types, and array-element shapes only, never values — capped by `SHAPE_MAX_DEPTH`/`SHAPE_MAX_KEYS`/`SHAPE_MAX_BYTES`/`SHAPE_MAX_RESPONSE_BYTES` so a pathological payload can't blow up memory or the reporter payload; `maybeDeriveShapeFromResponse` wraps it as a best-effort async helper for transports to call on a cloned response. `resolveRequest`'s passthrough outcome now carries the `unmatched` discriminant that flags an unmatched safe-method request; the fetch interceptor's own shape-observation hook gates on it to derive and report a shape. `SAFE_METHODS`/`isControlPlaneOrigin` are promoted from internal helpers to package exports so downstream transports can reproduce the same "unmatched safe method" discriminant instead of hardcoding a second method set that could drift. `detectShapeDrift` compares observed shapes recorded during a live session against the synced IR and reports additions/removals/type changes, with layered base-path matching — every base-path candidate (the schema's `baseUrl` path, bare, and the legacy `/api` guess) is tried against the observed path as given, then again after stripping up to two leading path segments, so observed paths under a versioned or prefixed base (e.g. `/api/v2/users/42`) still match their IR endpoint.
- **`@demokit-ai/react`**: `DemoKitProviderProps` gains `observeShapes?: boolean` (default `true`) — shapes are reporter cargo, so observation is a no-op whenever coverage reporting itself is off, regardless of this prop. Both the fetch interceptor's passthrough path and the msw transport's bypass path derive and report a shape for unmatched safe-method requests, so shape drift shows up identically no matter which transport is active.
- **`@demokit-ai/msw-transport`**: `createMswTransport` accepts an `onBypassResponse` option, invoked with the request/response pair whenever msw lets a request pass through to the real network — the hook the react provider uses to feed shape observation on the msw transport.
- **`@demokit-ai/db`**: `apiCallLogs` gains a nullable `shape` jsonb column (`Record<string, unknown>`, typed as `ShapeNode`) attached to `unmatched_request` events by the SDK transports' passthrough shape hook. No migration ships in this OSS package — the hosted dashboard's cloud repo owns the ALTER TABLE; self-hosted installs pick it up on their next `db:generate`/`db:migrate`.
